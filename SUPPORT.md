# Support

For installation/connection help, open a **Setup Problem** issue in [GitHub Issues](https://github.com/Chammy01/figma-designer-standalone/issues) once the repository is available. Check [Troubleshooting](docs/TROUBLESHOOTING.md) first. Use Bug Report for reproducible runtime defects and Feature Request for ideas.

Include version text, doctor results, what you tried, and relevant errors. Remove credentials, personal paths, private URLs, and design data. Private Figma files are never required. While the candidate remains unpublished/private, share support information only through the owner's established private review channel. Security issues follow [SECURITY.md](SECURITY.md), not public support.
