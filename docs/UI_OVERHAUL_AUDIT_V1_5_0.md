# UI overhaul audit — V1.5.0

The inspected baseline is cf4510348a190b1af9fad583963329aceaed7eab. An uncommitted compact presence experiment preceded this revised brief; its deterministic observer can be reused, but its card and small SVG scene are superseded.

The old shell uses a left navigation rail and one wide vertical content column. Design stacks connection explanation, intro, conversation, composer and workflow links. Prototype is a short explanatory page. QA and Browser contain canonical structured evidence and collapsed raw reports. Runs lists bounded history. Settings owns provider/model selection, Figma plugin setup and diagnostics; provider connection is a native dialog. Errors/recovery expose existing explicit retry/reconcile controls.

The current controller binds fixed element IDs. Preserve those bindings and service contracts while replacing visual hierarchy. Keep QA finding filters and truthful stale/FAIL/UNVERIFIED evidence. Keep model locking, input quarantine, one session, cancellation and receipt recovery authoritative. The activity observer uses real tool names/statuses, including structured Code Mode traces, without parsing reasoning or inputs.

Desktop is a sandboxed Electron shell around a dynamic loopback Node service, with one fixed plugin-folder preload method and separate preview origin. Minimum window is 900×650. No new IPC is required. Static serving currently uses literal file routes; production art must be explicitly enumerated, with no directory serving.

New composition: compact navigation + top connection strip; a central bedroom stage with stateful character/screen and a status bubble; a conversation column; composer below the stage. Supporting views receive the same warm studio shell with clearer task headers and evidence groupings, while preserving all IDs and canonical renderers.

Reference files actually supplied are JPEGs under design-references/1.5-agent-studio (not the PNG/v1.5 paths in the brief). They are user-provided generated references. Extract only character silhouettes and CRT screen interiors; optimize the canonical room, retain its casing, and exclude all raw sheets from the installed payload. Pixel Agents remains concepts only; no code/runtime/art copied.

Security: retain Host/Origin/CSP, authentication ownership, safe errors and desktop isolation. Art uses local image files, fixed allowlisted names and nearest-neighbor rendering. Do not change Figma authoring, motion, QA thresholds, runtime hashes or published Beta 3/4 assets.
