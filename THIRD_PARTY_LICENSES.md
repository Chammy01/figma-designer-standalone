The MCP executable statically includes the Go runtime and dependencies recorded by go version -m; module license texts above are collected from the existing module cache at preserved dependency versions. Read each retained text for its exact terms (MIT, BSD, Apache, and mixed licenses as applicable). Go modules not linked into the binary may appear as additional development notices. No dependency was upgraded.

The built plugin UI includes Svelte and its runtime dependencies; their original notices are included. Playwright is installed separately by npm ci, with its own notices and Chromium licensing in its installed distribution. Node.js, OpenCode, Figma Desktop, and browsers are not bundled project software; their installers carry their own terms.

The baseline installed Impeccable skill declared Apache 2.0 but did not include its full license/notice texts. They were retrieved from [its original upstream LICENSE](https://github.com/pbakaus/impeccable/blob/main/LICENSE) and [NOTICE.md](https://github.com/pbakaus/impeccable/blob/main/NOTICE.md) without rewriting original notice texts. The former engine was 0.1.11 and skill metadata is 4.5.0; its opaque engine and launchers are removed, and active instructions are archived. The ZIP retains only LICENSE/NOTICE. Platform reference and modern-screenshot notices were also retained from their named upstreams. The engine is not distributed, so its unestablished transitive provenance is no longer a public launch blocker. Retained source references and separate MIT-licensed browser helper notices remain preserved; see [engine audit](docs/SKILL_ENGINE_AUDIT.md).

Intentional local Figma MCP customizations include combine_as_variants, reaction hardening, structural comparison, and the additive source collector; upstream license/copyright statements remain intact. See docs/ARCHITECTURE.md. Other dependency notices remain separate from the root MIT license.
